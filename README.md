# オフラインゲーム集

**電波がなくても遊べる、日本語のミニゲーム集。** 通信ゼロ・登録不要・無料。

地下鉄、通勤電車、飛行機、山の中、災害時。回線が細い場所ほど「ゲームが読み込めない」で
困ります。このアプリは一度開けば、以後は完全にオフラインで動きます。
通信を一切しないので、ギガも減りません。

## 特徴

- **完全オフライン動作** — 一度開けば、以後は圏外でも遊べます
- **登録・ログイン不要** — 個人情報を一切集めません
- **通信ゼロ** — データ通信量を消費しません
- **軽い** — 全体で数百KB。画像も音声ファイルも使わず、図形と合成音だけで作っています
- **中断・再開できる** — 電車を降りても、続きから遊べます
- **ダークモード対応** — 端末の設定に自動で合わせます

## 収録ゲーム

| ゲーム | 内容 |
|---|---|
| ナンプレ | タテヨコとブロックに同じ数字が入らないように埋める |
| 犯人当て | 手掛かりを突き合わせて容疑者からただ一人を特定する |
| ソリティア | 色違いに並べて4つの組札を完成させる |
| スパイダー | 同じスートのKからAを8組そろえて取り除く |
| 麻雀ソリティア | 同じ牌を2枚ずつ取り除く |
| マインスイーパ | 地雷を避けて安全なマスをすべて開く |
| つみあげパズル | 落ちてくるブロックを積んで横一列を消す |
| マージ2048 | 同じ数をくっつけて大きくする |
| 15パズル | バラバラの数字を1から順に並べ直す |
| ライツアウト | すべての明かりを消す |
| 神経衰弱 | 同じ絵柄を2枚そろえる |
| スネーク | エサを食べて伸びる |

## 問題の品質について

数を並べただけの自動生成ではありません。出題のたびに、次のことを機械的に検証しています。

- **ナンプレ** — 解がちょうど1通りしかないこと。さらに、当てずっぽうを一切使わず、
  論理だけで最後まで解けること。難易度は5段階を狙って生成しています。
- **麻雀ソリティア** — 配置が必ず最後まで消し切れること。
  逆再生方式で配牌しているため、「絶対にクリアできない配置」が出ません。
  （牌をランダムに撒く一般的な実装では、解けない配置が混ざります）
- **15パズル** — 完成状態から合法手だけで撹拌するため、必ず解ける配置になります。
- **ライツアウト** — 消えた状態からランダムに押して作るため、必ず解けます。
- **マインスイーパ** — 最初にタップしたマスは絶対に地雷になりません。
- **犯人当て** — 出題ごとに「導ける犯人がちょうど1人」「解に必要な情報がすべて提示済み」
  「どの手掛かりも欠かせない（無駄も飛躍もない）」を機械検証しています。

## 技術的なこと

- 外部ライブラリ・外部通信・画像ファイル・音声ファイルを一切使っていません
- 効果音は WebAudio でその場で波形を合成しています（音源ファイル 0 バイト）
- Service Worker により、初回訪問の時点で全ゲームを端末に取り込みます
- ホーム画面に追加すれば、アプリとして起動できます（PWA）
